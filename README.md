# Shan Group Homepage

A compact bilingual research-group homepage for GitHub Pages.

## Deploy

Repository name:

```text
shanhuany.github.io
```

Upload all files in this package to the repository root:

```text
index.html
styles.css
script.js
.nojekyll
assets/
```

Then use GitHub **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important

This version intentionally keeps all people and publication content directly in `index.html`.
Only language/theme/menu interactions depend on JavaScript. This makes the site much more robust on GitHub Pages.

The portrait in `assets/huanyuan-shan.jpg` is the official portrait from the Shanghai Astronomical Observatory staff profile.
